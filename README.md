# MathBridge

**MathBridge** is a free, student-built interactive mathematics education website for high school and introductory college mathematics.

Live website: https://yanjiahuang722.github.io/mathbridge/

## Pages

- `index.html` — Home
- `learn.html` — lessons in number theory and probability
- `math-lab.html` — Euclidean algorithm, modular inverse, and binomial distribution visualizer
- `practice.html` — 10 multiple-choice questions with hints and explanations
- `about.html` — project mission and roadmap

## Local development

Open `index.html` in a browser, or use the VS Code **Live Server** extension. No installation or build tools are required.

## Publishing to GitHub Pages

The repository is deployed from branch `main` and folder `/(root)`.

1. Edit files in VS Code.
2. Test changes locally.
3. In GitHub Desktop, **Commit to main**.
4. Select **Push origin** and wait for GitHub Pages to redeploy.

**Note:** `index.html` must sit in the repository root, not inside a nested folder.

## Contents and safety

All practice feedback and calculations happen locally in the user's browser. No account, database, or tracking service is used. Browser JavaScript uses `BigInt` for exact integer arithmetic in the number theory tools.
