Subject 01

Number Theory

Number theory studies integers and the structures hidden inside them. Many of its basic questions can be explored using simple algorithms.

Key question: How can we find the greatest common divisor of two large integers efficiently?

1. Divisibility and the GCD

We say a divides b, written a | b, if b = ak for some integer k. The greatest common divisor, gcd(a, b), is the largest positive integer dividing both (when at least one of a, b is nonzero).

The Euclidean algorithm

If a = bq + r, then gcd(a, b) = gcd(b, r). Repeating this division eventually gives remainder zero, and the last nonzero remainder is the GCD.

252 = 2 × 105 + 42 105 = 2 × 42 + 21 42 = 2 × 21 + 0 gcd(252, 105) = 21

Why does this work? Any integer dividing both a and b also divides r = a − bq, and conversely any integer dividing b and r also divides a = bq + r. The common divisors are the same.

2. Bézout's identity

For integers a and b, not both zero, there exist integers x and y such that ax + by = gcd(a, b).

252(−2) + 105(5) = 21

The extended Euclidean algorithm computes both the GCD and one pair of coefficients. This also helps us find solutions to equations like ax + by = c and modular inverses.

Important: ax + by = c has an integer solution if and only if gcd(a, b) divides c.

3. Congruences and modular inverses

The notation a ≡ b (mod m) means that m divides a − b, with m a positive integer. A modular inverse of a modulo m is an integer x satisfying ax ≡ 1 (mod m).

3 × 4 = 12 ≡ 1 (mod 11) Therefore 3⁻¹ ≡ 4 (mod 11).

A modular inverse exists exactly when gcd(a, m) = 1. The extended Euclidean algorithm provides a way to find it.

Subject 02

Probability

Probability provides a mathematical language for uncertainty. A useful way to begin is to define the possible outcomes, the event of interest, and the assumptions about their likelihood.

Key question: How does a probability distribution change when we repeat an experiment?

4. Conditional probability

When P(B) > 0, the conditional probability of A given B is the probability of both events occurring, divided by the probability of B.

P(A | B) = P(A ∩ B) / P(B)

For example, roll a fair six-sided die. Let A be “the result is even” and B be “the result is greater than 3.” Then B = {4, 5, 6}, and A ∩ B = {4, 6}, so P(A | B) = 2/3.

Events A and B are independent if P(A ∩ B) = P(A)P(B). When P(B) > 0, that is equivalent to P(A | B) = P(A).

5. Binomial random variables

Suppose we perform n independent Bernoulli trials, each with success probability p. If X counts the successes, then X follows a binomial distribution.

X ~ Binomial(n, p) P(X = k) = C(n, k) p^k (1−p)^(n−k) E[X] = np Var(X) = np(1−p)

For 4 fair coin flips, the probability of exactly 2 heads is C(4, 2)(1/2)^4 = 6/16 = 3/8.
